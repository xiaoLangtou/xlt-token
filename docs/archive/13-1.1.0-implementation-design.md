## Step 1.2 · session 键迁移（device 后缀）

1.0 键：`${tokenName}:login:session:${loginId}`

1.1.0 键：`${tokenName}:login:session:${loginId}:${device}`（默认 `device = 'default'`）

- 不传 `device` 时行为与 1.0 等价
- 新增 `session-list:${loginId}` 维护在线 device 集合
- 旧键无 device 后缀的数据在首次登录时按 `default` device 写入新结构

完整键布局见 [架构设计 · 三类存储键](../guide/architecture.md#三类存储键) 与 [多端登录](../core/multi-device.md)。
